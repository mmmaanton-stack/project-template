# Project Template

A template structure for data science projects following best practices.

## Directory structure

- `raw-data/` — original, unmodified data files
- `processing-data/` — intermediate, transformed data
- `code-scripts/` — scripts and notebooks
- `documentation/` — project documentation
- `output-graphs/` — figures, tables, reports

## Conventions

- Use lowercase names, hyphens instead of spaces
- Prefix files and folders with numbers for sortability
- Document every step
